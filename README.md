# GreenTech-solutions
Final project ICT

This project is a simulated website for an imaginary company, the purpose of this project is to test
our knowledge and skills by simulating a real world experience by creating a website for a company given a specific criteria and expectations.

This website contains multiple pages, a home page, blog, about us, products and contacts.

The home page is an introduction to the website and the company

The blog is where the company posts tips for eco friendly and sustainable life tips

The about us page contains information about the company and team, origins and changes that happened oer the yrars.

The products page contains all the products the company has made
